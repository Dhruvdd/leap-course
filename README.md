# leap-course

A Python script that transforms PDF into a visually appealing PowerPoint presentation based on a chosen theme/template.  
Supports bullet formatting, custom layouts, and automatic text extraction.  

##  Steps to run the file:
1.	First, add your OPENAI_API_KEY in config.py.
2.	To execute, run the following command:
    - streamlit run streamlit_app.py
3. Upload the PDF file you want to transform.
4.	Add an image (the reference PowerPoint for the image is shared in the group).
5.	Click Submit.
6.	Once processing is complete, use the Download option to save your presentation.
